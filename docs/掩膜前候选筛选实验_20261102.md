# 原 Base＋Small 掩膜前候选筛选实验

用户于2026-11-02批准：先候选审计，再独立测试掩膜前筛选，重点核查K=64的速度、完整验证精度及遮挡目标新增漏检。全部实验文件、环境和缓存位于F盘。本轮不训练，不更换模型，不修改两份原权重、GT、原双掩膜NMS或四视图融合规则。

## 固定起点与验收

- 原ConvNeXt-Base、ConvNeXt-Small各434个张量严格恢复；检查配置固定的SHA256，结束重新核对。
- 保底原FP32四视图：P=94.4343%、R=90.0261%，TP/FP/FN=3105/183/344。单视图先与原对应单视图和20261031 FP16对应单视图分别比较，不能将单视图直接与四视图当同配置比较。
- 完整VAL仍为814图、3449个原GT、13张空图，所有标注异常保留。固定置信度0.75与各自P@R≥90均报告；在VAL选择阈值不属于独立测试集精度。
- 遮挡按冻结GT的V/A面积比分层，分别报告原已检出→新增漏检和原漏检→恢复，不把背景FP强行分配给遮挡组。
- V/A掩膜独立以原图mask IoU≥0.5匹配，使用对应box工作点。框精度不能代替分割质量，四视图目前只融合框。
- 所有方案均为实验候选，结果未达标时保留原模型，不自动晋级。子集通过也不能宣称完整VAL或实机通过。

## 执行阶段

1. **工程控制**：CPU策略/包装测试；相同原权重、相同输入下，关闭新增策略的新路径与旧FastAdapter逐张量比较框、分数及V/A掩膜。
2. **候选审计**：固定32图、173个GT、4空图，来自32个不同照片前缀，其中85个重遮挡GT。保存全部有效decoded候选框、初始两类softmax概率、最终概率、进入mask的索引和输出索引。推理不接收GT。
3. **离线筛选检查**：分别模拟K=256/128/96/64、初始阈值0.03、框NMS0.8及组合；被删原TP候选不等同于必然最终漏检，还需新推理验证。
4. **真实子集消融**：使用同一32图，独立测试K64、阈值、NMS及组合，报告固定0.75的box和V/A mask P/R、遮挡组召回；新候选全部由原权重新推理。
5. **稳态测速**：固定前8帧，3帧预热、2轮测量，单模型依次加载；计时含预处理、传输、模型、CPU输出及最终V/A轮廓投影，排除磁盘读取、模型加载和GT。同步分段诊断单独进行，不能冒充稳态FPS。
6. **完整VAL复核**：重点K64及有希望的组合，完整814图重推；需要时再验证paired双视图及原Base＋Small四视图融合。不能由单视图推定四视图结果。

512中心裁剪仅可作为局部输入速度模拟，不能称D405闭环跟踪精度；局部K16/24不是当前全图K64结论的自然推论。
