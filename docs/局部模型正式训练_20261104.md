# PApple 局部可见分割：正式训练与阶段验收

2026-11-04 用户授权正式训练。目标是在保留原 Base＋Small 全局模型的同时，训练用于采摘接近阶段的局部可见区域分割模型。本轮是单 V 基线，尚未增加 A 分支、教师蒸馏或接入 D405 实机。

## 固定配方

- 模型：YOLO26s-seg，从原官方 COCO 权重重新迁移 apple47→apple0，未接着 12 步烟测权重训练。
- 输入：完整视场 letterbox 640，batch=2，人工可见掩膜 mask_ratio=2，原生位图按同一果实 ID 保留。
- 数据：PApple train 2304 图/8579 实例/14 空图；development val 814 图/3449 实例/13 空图；test 807 图封存。
- 优化：10 个 epoch、共 11520 次更新，AdamW lr=1e-4、weight_decay=1e-4、梯度裁剪10；本轮无 mosaic/mixup/翻转，先固定基线变量。
- AMP：初始 scale=1024，growth_interval=11521，覆盖本轮预算不自动增大；非有限损失或梯度立即失败，不将跳步计为完成。
- Windows 加载：workers=0、pin_memory=False，不全量缓存到 RAM；F 盘可选逐值无损预处理缓存。
- 节点：训练前 epoch000，以及 epoch001/005/010；串行执行训练、完整验证和速度测量，禁止同时开多个 GPU 作业。
- 恢复：只允许完整 epoch 边界，保存并核对模型、AdamW、scaler、E2ELoss 调度、随机状态、采样规则及数据/源码哈希。部分 epoch 的工程检查点不用于续训。

原权重 SHA256：`3da1d83e31caec96f9300eb4064f4f62882c133c7c264d63dfe61a7c197837a4`。原 Base/Small 不进入本轮优化器。

## 评价口径

主指标为原尺寸可见 V mask IoU≥0.5 的一对一匹配，报告固定 score≥0.25 的 P/R/TP/FP/FN、自定义101点 mask AP50，以及候选域内可达到时的 P@R≥90。AP50不是 pycocotools 的多IoU COCO mAP，也不与原强模型94.4343%/90.0261%的完整果实框指标混比。

完整PR保留 score>0.001、max_det=300；相同分数按整组阈值统计，不能取 FP16 同分候选的一部分来抬高 P@R90。按原 V/A 面积比分层，重遮挡<0.40、中遮挡[0.40,0.70)、轻遮挡[0.70,0.90)、基本可见[0.90,1.00]，>1单列异常。报告每组召回/FN及匹配后 mask IoU，匹配后的 IoU 不代表漏检实例的质量。

原 train/val 共有309个果实身份，val为开发集。逐GT漏检和空图FP保留，GT不重标、不删难样本、不使用test选阈值。

速度独立测量：整图640/512、FP16、batch1、score0.25/max_det64，固定8图、预热5帧、5轮，原尺寸V掩膜和框交付CPU；记录均值/P95/FPS。排除磁盘、模型加载、绘图、相机采集、深度和三维优化，不能直接称D405整链路20Hz。低阈值PR验证耗时不能当部署延迟。
