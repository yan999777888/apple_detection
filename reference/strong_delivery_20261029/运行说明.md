## 二、单模型评估（复现单视图数字）

```bash
cd "E:/模块一/苹果检测成果包_20261029/07_运行环境与源码"

# ConvNeXt-Base，应得 P 92.00 / R 92.03（TP 3174 / FP 276 / FN 275）
PYTHONPATH="src;tmp" python -B tmp/eval_od_checkpoint.py \
  --checkpoint "../05_模型权重/convnext_base_c2_2304/validated_002304.pt" \
  --provenance assets/papple_val_provenance.json \
  --short-side 1024 --max-size 1280 --device cuda \
  --out ../02_证据/复核_base

# ConvNeXt-Small，应得 P 92.03 / R 92.06
PYTHONPATH="src;tmp" python -B tmp/eval_od_checkpoint.py \
  --checkpoint "../05_模型权重/convnext_small_joint2_2304/validated_002304.pt" \
  --provenance assets/papple_val_provenance.json \
  --short-side 1024 --max-size 1280 --device cuda \
  --out ../02_证据/复核_small
```

> **注意**：脚本里 `--provenance` 的默认值 `assets/papple/provenance.json` 是旧路径，实际文件是
> `assets/papple_val_provenance.json`，必须显式传，否则报文件不存在。
> 评估尺度必须是短边 1024 / 长边 1280——这是 90.23% 基线的口径，换成 800 会掉到 89% 左右。

输出目录里会得到 `raw_predictions.json`（与 `06_原始预测` 中同格式）、`summary.json`、阈值曲线等。

## 三、加水平翻转 TTA + 双骨干融合

```bash
# 1) 对 Base 做水平翻转推理（会自动校验原图可复现）
PYTHONPATH="src;tmp" python -B tmp/flip_tta.py predict \
  --checkpoint "../05_模型权重/convnext_base_c2_2304/validated_002304.pt" \
  --base-predictions "../06_原始预测/v1_base_原图.json" \
  --axis h --short-side 1024 --max-size 1280 --device cuda \
  --out ../06_原始预测/_hflip_base

# 2) Small 同理（--checkpoint 换成 small，--base-predictions 换成 v3）

# 3) 四视图融合 → P 92.75 / R 92.72
PYTHONPATH="src;tmp" python -B tmp/flip_tta.py fuse \
  --predictions "v1_base_原图.json" "v2_base_水平翻转.json" \
                "v3_small_原图.json" "v4_small_水平翻转.json" \
  --consensus-groups 0 0 1 1 --consensus-bonus 1.10 --isolation-penalty 0.90 \
  --score-modes mean --box-modes score_weighted --ious 0.45 \
  --view-weight-sets 0.65 0.65 0.35 0.35 \
  --write-best-predictions --out fusion_report.json
```

数据都在本目录下时把 `../06_原始预测/` 换成相对路径即可（见 `06_原始预测/说明`）。

## 四、环境

```cmd
pip install -r requirements.txt
```

- torch + torchvision（FasterRCNN 改造模型，需 CUDA 版）
- timm（ConvNeXt / Swin 骨干）
- 显存：单进程可用上限约 9–9.5 GB，ConvNeXt-Base 推理约 3 GB 足够；训练峰值 7.3 GB
- 系统内存 16 GB：评估时别同时加载大 checkpoint，会 OOM
