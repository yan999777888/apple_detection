# SSDA 训练图缺陷盲审

在本机打开 `experiments/ssda_blind_defects_v1/盲审材料/开始盲审.cmd`。如果由两位人员分别复核，可将“盲审材料”在同一父目录下复制两份，每份用不同的匿名代号。只把各自的材料和本说明交给审阅人。该入口使用本项目 F 盘已有的 Python 环境与图像库。

1. 输入自己的匿名代号。界面会回到该代号先前未填的第一条。
2. 看左栏整果位置和右栏原图局部，判断四段定位线中心的表面。选择“划伤”“虫伤”“其他／普通果皮”或“看不清／无法判断”。需要时可放大局部或翻回前页。
3. 每次选择都保存在“本地填写”。点击“导出已填结果”，同一文件夹下的“导出结果”会新增 CSV、JSON 两份文件；两者含匿名编号和判读，部分完成也可导出。再次打开请使用原代号。

34 条材料均取自原 SSDA 训练分区，逐图核验了来源文件、标注文件和原像素。人工结果保存在独立文件中。组织者应等所有人各自提交后，再用同级“组织者留存”的编号映射检查一致性、讨论分歧。这批材料以模型困难案例为主，从中统计的疑似漏标比例不能直接推算为全数据集的漏标率。
