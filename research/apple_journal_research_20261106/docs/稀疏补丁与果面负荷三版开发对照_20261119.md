# 稀疏补丁与果面负荷的三级品质分级对照

2026 年 11 月 19 日。三个分支均以原 native320 为起点。轻瑕找回最多的 V1 在自动裁片上判对轻瑕 8/15，但好果从 20/25 降到 19/25。V3 用疑似痕迹的面积和分布分级，找回了该好果，轻瑕却跌到 4/15。三个分支均未同时达到开发准入要求，止于开发评估，原模型继续保留。

## 三个分支分别学了什么

- **V1** 先复用原检测器唯一关联到当前果实的瑕疵框，再补充果面内部的可疑纹理，最多检查 8 个原分辨率局部补丁。固定 native320 和补丁编码器，用人工确认的浅伤、虫伤、果脐及高光对照训练局部验证头。开发 9 个明确伤区检出 6 个，28 个明确正常结构误报 1 个果脐。7 个 AF 开发伤区中，仅原检测框能覆盖至少一半面积的有 5 个，加入纹理提议后达到 7 个，最高分提议落在真实伤区的有 4 个。保存权重在全部 109 个有效开发输入上重推，等级 109/109 一致。[逐果输出](../experiments/grade_pairs_20261119/sparse_verifier_v1/development_predictions.json) · [位置复核](../experiments/grade_pairs_20261119/sparse_verifier_v1/native_replay_and_support.json)
- **V2** 增加提议来源、果色覆盖、反光比例及原 native320 在局部和邻域的响应。同时使用 79 个对准标记伤区的提议、65 个对准已确认正常结构的提议，并从训练好果中选出 456 个高响应纹理和 85 个高响应检测候选作为等级对照。后者的标签来自整果等级。原判重果保留，原判轻果改判好还需整果洁净证据。12 个开发节点中，自动好果守住 20 个时，轻瑕最多判对 5 个。[训练对照计数](../experiments/grade_pairs_20261119/grounded_sparse_v2/anchored_bank_audit.json) · [各节点及逐果结果](../experiments/grade_pairs_20261119/grounded_sparse_v2/history.json)
- **V3** 将补丁中的色差痕迹映射到统一果面网格，估计相对覆盖面积、最大单区面积、独立伤点数及分布范围。网格内按像素取最大支持度，只以新增面积计入后续提议。重复同一提议后 10 项特征最大变化为 0。同一合成画面放大两倍，归一化痕迹面积相差 1.9%。用 1,985 对同拍摄条件的等级排序样本和整果监督做一次正则化拟合。输出反映当前可见果面的相对痕迹，无法给出平方毫米伤口面积。保存权重经正式入口逐图重推，109/109 一致。[去重与尺度检查](../experiments/grade_pairs_20261119/fruit_surface_burden_v1/unit_geometry.json) · [逐图重推和单果测速](../experiments/grade_pairs_20261119/fruit_surface_burden_v1/replay_and_latency.json)

## 每次改动具体影响了哪颗果

| 对照 | 视图 | 找回的真轻瑕 | 新漏掉的真轻瑕 | 真好果变化 |

| native320 → V1 | 整图 | 213412、213455 | 213546 | 无 |
| V1 → V2 | 自动 | 无 | 213412 | 无 |
| V1 → V2 | 整图 | 无 | 无 | 无 |
| V2 → V3 | 自动 | 无 | 213354、213425、213446 | 213421 恢复为好 |
| V2 → V3 | 整图 | 无 | 213412、213442 | 172505 恢复为好 |

V1 判为轻瑕的 8 个真轻果中，4 个最高响应来自原检测框，4 个来自纹理提议。误降的两张好果各来自一种提议。213421 的纹理提议落在蒂旁可见褐斑，213514 的检测框落在闭环褐线。两处与部分二级苹果的浅痕外观相似，现有图片不足以判断病因或改写作者等级。图册同时展示每颗果的实际裁片与最高响应部位。[逐果实物图册](../experiments/grade_pairs_20261119/sparse_verifier_v1/dev_sparse_light_predictions.jpg)
